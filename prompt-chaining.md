- Si la lección trata sobre contexto, deberá mejorar un prompt agregando contexto.
- Si la lección trata sobre roles, deberá crear un prompt utilizando un rol adecuado.

ENTREGA DE EVIDENCIA

Eliminar la sección actual de "Entrega de Evidencia" de las lecciones del Módulo 3.

Reemplazarla por una nueva sección llamada:

💬 Compartir Prompt Utilizado

Esta sección deberá permitir que el estudiante registre un prompt real que utilizó con una Inteligencia Artificial.

--------------------------------------------------

LA NUEVA SECCIÓN DEBERÁ CONTENER

1. Un área de texto llamada:

"Prompt que utilizaste"

Aquí el estudiante escribirá el prompt que realmente utilizó para realizar la actividad.

2. Un contador de caracteres en tiempo real.

3. Un segundo campo de texto llamado:

"Última conversación o consulta realizada"

Aquí el estudiante deberá copiar la última consulta que realizó a la IA que utilizó para resolver la actividad.

Puede ser ChatGPT, Claude, Gemini, Copilot, Cursor, OpenCode u otra herramienta similar.

4. Un botón llamado:

"Guardar evidencia"

--------------------------------------------------

VALIDACIONES

Antes de guardar:

- Verificar que ambos campos tengan contenido.
- Mostrar mensajes claros si falta información.

--------------------------------------------------

FUNCIONAMIENTO

Al presionar "Guardar evidencia":

- Mostrar un mensaje de éxito.
- Guardar temporalmente la información utilizando el sistema de almacenamiento disponible (LocalStorage mientras no exista un backend).
- Si el estudiante vuelve a abrir la lección, recuperar automáticamente la información previamente guardada.
- Permitir editar y actualizar la información en cualquier momento.

--------------------------------------------------

PROGRESO

Una vez guardada correctamente la información:

- Marcar automáticamente la actividad como completada.
- Actualizar el progreso de la lección.
- Mantener compatibilidad con el sistema de progreso existente.
